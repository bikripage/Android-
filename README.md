# Smart Print Desk — Android source package

This package adapts the supplied Electron app's web UI for Capacitor. The original Firebase login, Firestore live jobs, PeerJS transfer, and E2EE logic are retained in `www/index.html`.

## Important status
This is an Android-ready **source project**, not a tested APK. The native Android folder is generated by Capacitor and must be created on a computer with Node.js, Android Studio, and Android SDK. The custom print bridge source is provided, but must be registered in the generated Android app and tested with a real printer.

## Setup
1. Install Node.js LTS and Android Studio.
2. In this folder run `npm install`.
3. Run `npm run build`.
4. Run `npx cap add android` (first setup only).
5. Copy `android-plugin/SmartPrintPlugin.java` into the Android app package folder and register the plugin as described below.
6. Run `npx cap sync android` then `npx cap open android`.
7. In Android Studio, build/run on a phone.

## Native plugin registration
The plugin Java class is a reference implementation. Capacitor plugin registration may differ by generated project version. In `MainActivity.java`, register it using `registerPlugin(SmartPrintPlugin.class);` (and ensure the Java package declaration matches the app package).

## Printing
- Android uses the system Print Manager; users choose printer and options. It is not silent printing.
- The included bridge supports image files via Android WebView printing. PDF support is device-dependent and needs additional native PDF handling/testing before release.
- Electron's old silent-print handler remains in the original `main.js` project; this Android package does not use Electron.

## Security notes
The original source stores the shop app password in localStorage. Review this before public release; prefer a safer credential/session design. Firebase client configuration is not a secret, but Firestore security rules must enforce authorization. Never ship an app until rules are audited.
